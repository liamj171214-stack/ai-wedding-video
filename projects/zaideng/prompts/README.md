## 跨镜硬性连续性约束

1. **空间与轴线（180° 轴线锁定）**：三台机位均位于木桌同一侧（见 [cafe-blocking.svg](../../../examples/cafe/assets/cafe-blocking.svg)）。全段保持**男左女右、左窗（金黄秋叶暖侧光）、正后木质书架、右后长虹玻璃木门**不变，严禁左右镜像翻转。
2. **人物与妆造一致**：
   - **周远**（[zhou.jpg](../../../examples/cafe/assets/zhou.jpg)）：成年东亚男性，利落黑短发，右颧骨下方小痣，深藏蓝圆领针织衫。
   - **林夏**（[lin.jpg](../../../examples/cafe/assets/lin.jpg)）：成年东亚女性，自然低马尾与两侧微碎发，双排扣米色风衣（深棕肩章扣）内搭深炭灰衬衫。
3. **道具数量与推杯落点**：深胡桃木桌面始终保持**两只哑光黑陶瓷杯**（内盛浅琥珀色热茶/泡沫）与**中央并排斜放的两张浅米黄齿边纸车票**。`15a` 推杯幅度控制在半掌距离内，落点停在左中桌面、不越过中央两张车票，使 `15a` 出点杯位与 `15b`、`15c`、`15d` 参考构图自然衔接；禁止多出第三只杯子、茶壶、勺子或手机。
4. **声音与口型纪律**：
   - **Flow 主线**：优先使用 Ingredients 绑定角色四视图与空场，并以对应机位图（`shot-A/B/C.jpg`）作为构图或首帧基准；开启原生音画联合生成，保留原声，不加背景音乐或旁白。
   - **Grok 对照版**：若入口仅支持单张首帧图＋文本提示词，直接上传对应机位图（`shot-A/B/C.jpg`）作为首帧，提示词只描述首帧之后的动作因果、分时台词、闭口倾听和环境拟音，不改写既有构图。
   - **音色跨镜核对**：周远（温和低沉、克制诚恳的成年男声）与林夏（轻柔清晰、沉静克制的成年女声）在 `15b`、`15c` 中须各自保持稳定声线，说话时另一方严格闭口。
