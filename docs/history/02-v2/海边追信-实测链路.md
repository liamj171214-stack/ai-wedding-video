# 海边追信实测链路

以一场能独立看懂的戏作为生成和验收单位。2026-11-17 的小样在同一个海滩完成信封脱手、追跑、捡起、相视大笑。用户确认这版比上一版更有故事感和流畅感。

## 这一版怎样做出来

1. 在已有 Flow 项目（项目链接仅存本地） 选择已上传的 [Jonathan Borba 公开婚纱照](https://www.pexels.com/photo/30822475/)。图片在提示中仅作为成年角色外貌和婚礼服装参考。
2. 在同一次生成里描述三个镜头，并固定环境、道具与方向。手部近景里红火漆信封脱手向右飞 → 侧面全身跟拍两人向右追 → 低机位交代信落到沙上，再让女方捡起、抬头，两人笑起来。要求傍晚海滩、白西装和白纱、无旁白字幕。海滩根据文字生成。
3. Flow Agent 使用 Omni 1.2 Flash，单条 15 秒、16:9，页面显示 60 点。下载 720p 原始文件。本次直接保留模型内的剪辑与音轨。
4. 用 FFmpeg 全片解码、ffprobe 读规格，并每秒抽一帧检查。下载文件 15.04 秒、1280×720、H.264/AAC。用户看过视频后确认方向。

原片及网页截图保存在本地制作项目。

## 复用方法

- 每场描述一个动机、一个看得见的动作和一个结果。相邻镜头标明同一件道具、人物站位、移动方向、服装及光线。
- 同一场优先测试连贯的多镜生成。单场内缺镜再用已通过的画面作参考补拍，剪掉动作断开的部分。各场确认后统一剪辑，用环境声或对白连接切点。
- 人物、衣服、独立场景图和道具图分别建索引。海边实测用的是人物照片加文字换景。三维建模、独立背景参考图锁定及跨年龄同脸，留给后续验证。
- 留下参考图、提示词、导出文件、点数和审片结论。审片先静音看动作因果，再开声看切点与声音。已发现的瑕疵是信封飞行偏悬浮，追跑偏慢。
