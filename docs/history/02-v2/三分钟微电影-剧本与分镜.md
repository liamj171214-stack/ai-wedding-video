# 把明天寄给你 · 三分钟微电影

虚构新人林夏和周远从未见过彼此的童年，却都习惯用笔记录重要的事。他们成年后在红墙外相遇。后来因为一次失约吵架，才学会把话说清楚。婚礼那天，周远读出他们当年写给未来的信。

**全片 3:00，包含标题与片尾。**前 40 秒交代两条成长线，中间 111 秒给相识、相恋和关系转折，最后 29 秒收束婚礼。海边追信直接用已确认的 15 秒镜头。

## 开拍前的素材准备

- **人物**：沿用上一版成年双人的公开参照。分别制作童年、少年、成年参考页，保留可辨认的发色、脸型和眼睛。儿童形象是虚构角色，先检查角色读不读得清。前两场用同一动作和一件随人成长的道具帮助认人。
- **场景**：儿童教室和住宅外景、故宫风格红墙、书店咖啡角、海滩、海边礼堂，分别保存无人环境参考和景别草图。同一场的远景与特写沿用同一套光线和站位。
- **道具和声音**：旧笔记本、纸飞机、两只杯子、米白信封和红火漆。给信封保留完好、追跑后带沙痕、翻开后三种状态。对白用少量可见口型，必要时放在反应镜头上。用同一人声音色贯穿成年段。

## 分批制作和验收

第一批先拍 **00:40–00:57 相识**及 **01:31–02:04 失约与和好**。相识可检验同一空间的运动和道具，争吵与和好检验表演、对白和反应剪辑。先让这两处静音也能看懂，然后补成长、恋爱和礼堂各场。已通过的海边原片保留，只有与前后场服装、沙痕或声音接不上时才补拍衔接镜头。

每场按约 8–15 秒生成或用短镜补齐，多次生成只发生在明确不通过的镜头。将实际镜头放进时间线再调整节奏，最终总长 180 秒。审片同时检查两张脸、方向、眼神、手部和道具，打开声音复核对白、风声、室内底声与音乐的衔接。
