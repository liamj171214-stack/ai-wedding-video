# 把明天寄给你 · v1

虚构故事。红墙下写给未来的一封信，在沙滩被风吹走，最终出现在海边礼堂的誓词旁。对白由同一个叙述者转述，避免对口型。角色使用同一组公开照片作图像参考，背景独立采集。角色身份是参考图驱动的视觉一致性方案，尚未建立可摆姿态的三维模型。

## 返工方式

替换 assets 中对应镜头，在 render.py 中调整该镜的文件名和动效类型，再运行 python render.py 和 python finish.py。v1 的重点是审故事、转场、选景与造型。新镜头的连续人物动作还未做完，Grok 上传生成关键帧时浏览器连接断开。没有将构图推镜冒充人物运动。优先返工 8–15 秒红墙走路与 22–29 秒海边奔跑，再用礼堂实动替换收束段。
