# 《把明天寄给你》全流程复盘与重制方案

**三分钟版审片不通过。**用户认可 15 秒海边追信的故事感和流畅度。三分钟版的静态画面占比过高、旁白听感欠佳、角色没有在画面里说话。重制按有声表演逐场制作，图片只在有叙事作用的转折处短暂出现。

## 做过的四版

| 版本 | 实际链路 | 审片结果 |
|---|---|---|
| 34 秒工具样片 | Pexels 同一对人物 → Grok 和 Flow 图生视频 → MiniMax 普通话旁白 → Remotion 排版混音 | 跑通工具和交付，故事范围有限 |
| 46 秒故事预演 | 同一人物参考＋独立古建、海滩、礼堂素材 → ImageGen 换装和换景 → 关键帧运镜、旧动态镜头和旁白 → FFmpeg | 用户认为缺乏微电影流畅感。画面没有演出旁白讲的关键动作 |
| 15 秒《海边追信》 | 公开婚纱照作人物参考，文字指定海滩 → Flow Omni 1.2 Flash 一次生成多镜，15 秒 60 点 → 下载原片，检查断点与动作 | 用户认可。脱手、向右追、捡回、笑四个动作组成完整因果。信封飞行稍显悬浮 |
| 180 秒审片版 | 12 场分镜 → Flow 新请求限流 → Grok 补出 6 段 → 加入旧海边原片、ImageGen 关键帧、公开空镜 → MiniMax 合成四段人声 → FFmpeg 拼接混音 | 7 段动态合计 72 秒，占 40%。其余 108 秒包括静态关键帧、空镜和标题。画面角色无同步对白。文件通过技术检查，内容审片不通过 |

## 为什么扩长后质量掉了

1. 我在画面不足时先补足了 180 秒。相恋、失约、和好都有片段，但一场中真正的行为和反应太短，其余时间靠静帧与旁白。15 秒版之所以流畅，是因为几乎每一秒都在推进同一个动作。
2. 一开始的视频提示主动要求无对白。剪辑时把标准合成旁白和结尾誓词铺到画面上，丢掉了演员说话时的停顿、重音、眼神和对手反应。补一句配音无法补回整场表演。
3. 同一对人物的照片只提供参考。咖啡馆不同日期的座位、服装、人物长相以及唐装段的一致性依赖各次生成，缺少逐场锁定与返工。抽帧与完整解码也无法证明全片表演和听感合格。

## 重制方式

**先做一段 20–30 秒有真实对话的咖啡馆戏，再扩到三分钟。**用失约和道歉验证双人表演。把等待、离开、次日主动沟通分开制作，彼此之间用杯子、空椅和同一扇窗接起来。Seedance 支持图、视频、音频参考及音视频联合生成，可作为主试路线。[Seedance 2.5 官方介绍](https://seed.bytedance.com/en/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5) · [火山引擎短剧工作台](https://docs.volcengine.com/docs/drama-creation/short-play-creation?lang=zh)

1. **按场写表演稿。**每场标一个变化，写清谁先说、说完等多久、对方怎么反应。先试录两位角色的声音，核对普通话、情绪和停顿。保留少量对白与环境声，旁白只在确实需要跨越时间时考虑。
2. **单独准备角色、声音、背景和道具。**为两位成年角色固定正侧脸、当场服装和音色，同一间咖啡馆准备无人环境图及站位图。童年与少年用各自参考。素材图主要作为生成输入，成片图片用于童年照、信件等确有叙事作用的转折。
3. **同场生成对白和画面。**用 Seedance 支持的参考与台词写法为每位角色绑定声音；安排开口、闭口倾听、反应、镜头方向与环境声。短句先验证，再扩长。采纳前核对入口的模型、额度与角色参考支持。[Seedance 2.5 提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)
4. **通过一场再扩到全片。**追信原片可以保留。主线其余场均以实际动态表演覆盖。先锁 8–10 场实拍长度，再剪到 180 秒。图片只作短插入，时长随剪辑确定。MiniMax 只在试音获认可后补台词或临时声音，FFmpeg／Remotion 负责确定性的字幕、混音与交付。
5. **以可播放场次验收。**静音看动作因果和对手戏；开声听两句对白是否好听、说话人与口型是否一致、雨声和杯声是否服从画面。再核对角色、衣服、信封和站位。整场通过后再扩量。完整解码和场地试播留在交付验收。

### 首轮对话试拍

- 雨夜。空椅旁两杯咖啡，男方推门、开口想解释。女方握住包带，看他一眼，说「我等了很久。下次来不了，先告诉我。」说完停一拍再走。镜头留给男方的反应。
- 次日。男方已经坐下。女方进来，他推过去一杯热茶，说「昨天让你白等了。」她坐下，试一口，说「今天倒是挺准时。」两人笑，杯子轻碰。
- 两段留同一个窗边位置，机位保持在桌子同一侧。仅保留两位角色的对白、雨或街声、椅脚和杯声。目标是验证两人能否轮流说话、自然倾听，以及动作和声音能否接起来。

这份记录整理了实际链路和复拍方案。Seedance 新入口、参考图可用性及双人音画效果仍待实测。

## v0.2 外部评审采纳项

首轮试拍范围收窄到「次日咖啡馆和好」。雨夜等待与跨日转场放到第二轮，便于分别判断表演和跨场连续性。当前项目使用虚构角色验证表演，真实新人版另核验肖像来源、授权和平台入口。

- 00–05 秒，双人中景。男方已经坐在同一张窗边桌旁，女方走进来停在空椅旁。
- 05–12 秒，男方推茶，抬眼说「昨天让你白等了。以后来不了，我先告诉你。」女方保持闭口，听完再低头看茶。
- 12–19 秒，女方坐下，抬眼说「今天倒是挺准时。」拍清她开口与男方听完才笑的反应。
- 19–25 秒，回同框。杯子轻碰，两人相视。只留对白、桌椅和室内底声，暂不加旁白或音乐。

试拍交付是完整有声场次、两位角色的试音、原始输出和一份简短候选记录。记录每次用的角色与场景参考、音色、模型、失败原因和获选镜头。审片开声检查台词归属、口型、语气、倾听和反应，静音检查动作与眼神。音画联合生成优先用现有可访问入口，Seedance 列为同场对照，入口与真人或虚构角色的素材条件按实际产品核对。如果角色音色或轮流说话不稳定，改用独立表演源驱动，再比较效果。

现有 render.py 已可用于复现审片版，其按文件存在回退静帧、尾帧填充及去除源镜音频的规则只适用旧预演。新成片流程要求每个关键场有通过审片的动态候选及明确音轨选择。缺镜保持审片状态，保留源镜音轨，有必要时才选择性替换。尾帧填充是旧脚本的潜在风险，评审未逐帧确认有实际冻结。

首轮先验证对白表演，第二轮再拼雨夜与次日约 60 秒段落，最后进入三分钟剪辑。童年仍保留为主线的一部分，先压缩为画本和纸飞机两个短动作，具体用时跟随可用表演。此处更新了制作规则，尚未运行复拍或修改旧版渲染脚本。
