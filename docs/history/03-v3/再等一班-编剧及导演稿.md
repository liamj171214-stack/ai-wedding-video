# 《再等一班》编剧及导演稿

三分钟虚构婚礼微电影。主题是两个人学会照顾对方的节奏。核心道具是一枚折过的纸车票，贯穿成长、相遇与礼堂。沿用可用的海边追信作为轻松段落时，信封在前场明确用来装车票。

## 编剧稿

**人物。**林夏擅长把要说的话画下来，遇到变故容易先收拾好自己再离开。周远总赶着解决问题，习惯替两人做决定，忘记说清过程。

**故事。**小时候，林夏在站台等妈妈，边等边画两把并排的椅子。周远第一次陪父亲坐错车，父亲在废票上画了一个箭头，带他走回月台。成年后，他们在同一个站台遇上停运。周远拿着图想给她指路，发现自己也走错了。两人等下一班，聊起这张旧站线图。后来一起租画室、布置窗台，约好要去看海。婚礼前，周远以为换到更早的一班是惊喜，提前走了，林夏带着画等在旧车次。碰面后，她第一次直接讲清楚自己为什么生气。第二天他先坐到她身边，手里拿着两张同一班车的票，也把“你想什么时候出发”问了出来。他们才终于一起去了海边。婚礼上，林夏把留着的车票递给他，说出后来那班车为什么值得等。

## 导演稿

共 24 镜、180 秒，时长用于预估。生成候选回来后以表演调整剪点。主要场景为旧站台、当代站台、小画室、雨夜站厅、次日咖啡角、海岸、海边礼堂，空背景作为独立参考。站台戏从轨道同侧拍，咖啡角保持窗左门右。掌握人物位置再做正反打。成年角色用同一组参考；童年以动作与道具帮助辨认。镜内台词由角色本人演出。文字出现在道具上时留给后期排字。
