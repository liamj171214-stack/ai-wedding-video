# 《把明天寄给你》三分钟审片版

虚构剧情。第一轮成片用于审叙事、节奏、人物与场景切换。核心动作使用图生视频，部分场间连接和成长片段使用生成关键帧或公开场景图运镜。

## 素材与运行

- 成年参考为 Jonathan Borba 的 [Pexels 婚纱照](https://www.pexels.com/photo/30822475/)，童年是虚构形象。背景和服装为生成演绎。
- 公开场景图及作者：征宇 郑 [故宫外景](https://www.pexels.com/photo/20683353/)、TonyNojmanSK [故宫建筑细部](https://www.pexels.com/photo/13073913/)、Agustin Muñiz [海岸](https://www.pexels.com/photo/20347429/)、ZhiCheng Zhang [海边礼堂](https://www.pexels.com/photo/36298681/)。使用条件见 [Pexels 授权说明](https://www.pexels.com/license/)。
- Flow 批量和单场尝试均遇到请求频率限制，本轮新增动态镜头转用 Grok。旧海边素材是 Flow Omni 1.2 Flash 的 720p 源视频。Grok 新片按实际下载规格使用并统一到 1080p 时间线。
- 童年与成人过场格图用 ImageGen，旁白与末尾誓词使用 MiniMax 标准合成音色，音乐使用之前的原创合成曲，环境音由海边原轨与本地合成组成。
- `assets/` 保存源文件，`render.py` 写明各镜的文件和时长，`ambience.py` 生成环境声。已有素材时，运行 `python render.py` 可重渲染。

同场动态动作已经加入，跨场仍有衣饰、人物神态和光线差异，部分关键帧可看出静态痕迹。导出为 1080p，源镜头清晰度仍随原片而变化。现场实际屏幕与音响待试播。

## 导出检查

本次时间线使用 29 个剪辑片段。六段新 Grok 动态素材及一段 Flow 海边原片在成片合计 72 秒，余下是空镜、生成关键帧运镜及片头片尾。咖啡馆原片裁掉前 2 秒，压缩从等待到离开的交代。成年角色参考跨平台复用，唐装写信一场脸部变化和内嵌黑边较明显，部分源片清晰度低于海边片段。

1080p 主文件通过 ffmpeg 完整解码。ffprobe 核对为 180.000 秒、1920×1080、24 fps、4320 视频帧、H.264 与 AAC 双声道。音频数字峰值 -2.8 dBFS。核对了新素材关键帧，未在婚礼现场试播。
