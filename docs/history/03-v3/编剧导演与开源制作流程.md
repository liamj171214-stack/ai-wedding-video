# 婚礼微电影制作流程

创作要求来自用户，人物动机、剧情和结尾由编剧完成。导演把剧本变成演员能演、摄影能拍、剪辑能接的分镜。每个环节留下一份可检查的交付物，生成服务按已经定稿的分镜工作。

## 先修正已经发生的问题

| 问题 | 新版改法 |
|---|---|
| 把用户举的桥段和上一版样片直接拼成全片 | 用户要求保留成长、相遇、关系变化和婚礼。编剧另做独立故事，交代人物想要什么、为什么改变，以及婚礼如何回应前情 |
| 有分段时间表，但没有按全片剧本写出具体表演与逐镜设计 | 剧本写到完整场、行为、对白和反应。导演为每场写入场和出场状态、机位、视线、切点和声音 |
| 180 秒成了硬目标，动态表演只有约 72 秒 | 先拍齐支撑剧情的动态场次，剪完再核对时长。照片只在有叙事作用的转折短插 |
| 静帧补位、尾帧填充、去原音和外置旁白掩盖缺镜 | 旧版脚本保留作复现。新制作中缺关键镜即记录待补，保留生成源声；旁白试音、台词和口型分别审 |
| 脸、服装、桌位、道具状态随生成变化 | 角色正侧脸、音色、每场妆造、独立背景、站位和道具分别有版本，拍摄时明确引用 |
| 以抽帧、分辨率和完整解码代替视听审片 | 先完整连播，核对对白、动作和跨镜连续性，再做交付规格验证 |
| Flow 限流后更换工具但沿用旧的无对白提示 | 更换引擎前以同场、同台词验证表演。若只能生成动作，档案中明确该镜仅作为无对白动作候选 |

既有结果与证据边界见[复盘](全流程复盘与重制方案.md)。本轮完成的独立故事及导演逐镜稿见[《再等一班》](再等一班-编剧及导演稿.md)。

查阅范围是仓库页面、README 和可见目录。各项目的模型接口、许可和效果需以实际版本验证。尚未安装或跑通这些项目。当前先用已有目录实践轻量流程。

## 逐步制作与交接

1. **创作要求。**确定观众、用途、画幅、虚构范围和需要保留的主题。结果是一页创作简报。
2. **编剧。**提出原创主线和人物弧光，写完分场剧本。每场记录人物目标、阻碍、可见动作、台词和发生的变化。检查去掉旁白后主线是否成立。
3. **导演。**通读并修改剧本；建立场景调度和声音节奏。逐镜记录时间、景别、机位、出入状态、对白归属、倾听反应、环境声和切点。输出全片可拍分镜。
4. **美术和声音。**准备人物多角度、逐场服装、可独立替换的背景、道具状态和两位角色试音。每个镜头引用具体资产版本，确认同场机位和站位。
5. **试拍。**先完成一场双人有声对手戏。验收两人可见开口、互相听话、反应和物件连续。用可访问入口做少量候选，固定同一场才比较模型。
6. **逐场生成与补拍。**按导演稿生成候选，保留源音轨和生成记录，审查跨镜连续性。缺哪一项就补哪一镜，保留候选及取舍。
7. **剪辑、声音、调色。**以表演决定剪点，分轨剪对白、环境、拟音、音乐，锁画后上字幕和统一色调。
8. **审片与交付。**先按完整有声成片验收剧情、表演与声音，再验证播放文件和实际场地。保留版本、素材来源、返工和用户反馈。

分角色职责可以在同一次制作中分阶段完成。编剧先交底稿，导演独立指出不可拍和难接的地方，再由编剧修订，随后才生成。暂不引入多代理编排或部署平台。
