# 有声短剧制作流程

《再等一班》咖啡馆试拍已验证两种现有入口可以输出普通话双人对白和同期动作。用户反馈「还可以」，记为基础试拍可用，成片质量仍待精修。人物跨镜一致性、音色跨镜延续、正反打以及场景复用是下轮验证目标。

| 工序 | 输入与交付物 | 通过条件 |
|---|---|---|
| 编剧 | 用户创作要求 → 原创故事、完整分场、动作与短句对白 | 关键场有可见冲突、反应和结果 |
| 导演 | 剧本 → 机位、站位、视线、节奏、说话与倾听顺序 | 全片镜头表完整；每场可按编号补拍 |
| 美术与声音 | 定稿分镜 → 人物、服装、音色、空场、道具及白模参考 | 正侧脸可识别，机位反向看仍是同一个房间，试音和角色适配 |
| 有声试拍 | 固定资产与同一台词 → 同框、男方近景、女方反打 | 开声看说话人、口型、停顿与自然反应；静音看调度连续 |
| 逐场制作 | 已通过的测试 → 各场候选、原片音轨、选用片段及补拍记录 | 关键表演齐备，缺镜记录待拍 |
| 后期与审片 | 已选素材 → 剪辑、对白/环境/拟音/音乐分轨、字幕和成片 | 实看实听通过后，再跑规格、解码并做场地试播 |

## 这次可直接复用的试拍方法

1. 定一个空间和两个人的站位。指定男左女右、窗左门右。用动作和分时台词写清推茶、道歉、女方闭口倾听、停顿、女方回应、碰杯。
2. 先用同框中景检查两个人能否轮流说。上一轮 Flow 约 15 秒，Omni 1.2 Flash 单条 60 点，原片 1280×720。Grok 网页约 10 秒，原片 672×448。两路台词长度不同，作为候选观察。
3. 下载原片并留源音。FFmpeg 完整解码，Whisper 辅助对词，抽帧查手、杯、站位。Flow 首轮转写曾误识别，截取主要说话时段并提高分析副本音量后核对。正式判断应开声看片，记录具体时间点与问题。
4. 下一轮固定角色和场景后，用一条同框确定动作和声音基准，再补两条近景。保留同框连续性作为对照，保持咖啡桌定位；逐镜选择保留或重做的声轨。
