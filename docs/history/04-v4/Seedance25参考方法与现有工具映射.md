# 参考 Seedance 2.5 制作方法，用现有工具实现

本项目采用 Seedance 2.5 的素材准备、导演描述与分场验收方法。影像生成沿用已试拍的 Flow、Grok。ImageGen 用于人物与场景素材，Blender 可做走位预演，MiniMax 可做试音，FFmpeg／Remotion 用于后期。平台输入能力单独验证。

## 对照官方指南梳理资产

| 素材 | 应保存什么 | 每镜怎样用 |
|---|---|---|
| 主体图与多视图 | 每人一张中性正脸为主，补 45°、侧脸和全身。分开保存面孔与逐场妆造，统一角色编号 | 正反打只附影响该镜的角度。同一人物多图明确归到同一角色 |
| 主体音视频、音色与台词 | 每人单独的短表演或试音，标记情绪、语速与语句；台词稿标说话人及听者反应 | 分开写清“参考音色”或“照着表演节奏说”。两人的声音分别绑定。实际入口若只接受文字，就记录为文字控制 |
| 空场与道具 | 一张场景主图、俯视图、各机位无人背景。杯子、车票、信封分开，记录使用前后的变化 | 场景图管布局、光向、陈设。道具图管形状和颜色，交接表管谁拿、放在哪里 |
| 运动或表演视频 | 短段走路、推茶、转头、递物，或可复现的运镜参考 | 只复用需要的动作路径、节拍或运镜。不要把视频里的服装、脸和背景误当参考 |
| 粗白模视频 | Blender 中用简单体块搭墙、门窗、桌椅和人物占位，先定轴线、机位、空间比例与路径 | 优先解决走位、景别与运镜。复杂手势、拥抱接触和口型另用表演素材或逐镜控制 |
| 故事板、关键帧、首尾帧 | 线稿画站位、近远关系与构图。关键帧给重要动作状态。首尾帧描述镜头从哪里开始、到哪里结束 | 分镜板可给导演与组接用，也可按入口能力当参考。用关键帧约束动作端点，保留中间运动的时间 |
| 风格与声音环境 | 每场一套光线、色彩、质感参考。留环境声、动作拟音、配乐分轨与用途记录 | 风格图只管色光质感。对白场保留可懂的同期声，环境音和配乐后期分轨 |

官方指南给出了参考生视频、白模、运动、音频、故事板、关键帧、编辑与续写等案例。多视图小规模试用有效与否由镜头验收决定。官方对复杂素材有数量和时长建议，项目先按贡献选少量有效素材，逐项添加以定位变化。[Seedance 2.5 提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh) · [模型说明](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh)

## 按场景选择实践

| 任务 | 优先准备 | 本项目实践 |
|---|---|---|
| 双人对白与反应 | 双人同框基准、各自近景外貌、同一房间的反打背景、两人声音、分秒台词 | 先同框做完整交换。再补单人反打。标说话人、闭口倾听者、停顿、看谁与手的位置。项目先做咖啡馆第 15–17 镜 |
| 进门、走廊、站台 | 空间俯视图、简单白模、走位和机位短视频 | 先确定从哪进、停在哪里、向哪看；不能直接传白模视频的入口，用白模导出首帧与关键帧作构图，再用文字描述路径 |
| 奔跑、转身、拥抱 | 动作或双人走位参考、人物造型与背景、入出关键帧 | 海边追信拆成脱手、跑、捡、反应。始终记录两人移动方向、信封的位置。接触动作优先短镜和可见四肢，盘点手型和衣服连续性 |
| 递车票、推茶、拆信等特写 | 道具主参考、清晰手位及动作前后状态 | 用短镜交代一件事。杯底、纸张和火漆声标到动作发生处。后期添加必须准确的文字 |
| 跨时间、跨地点 | 各自空场参考、对应妆造、光线及道具状态 | 为每个地点单独生成。用接得上的动作、道具或环境声跨切点。图片只用于有叙事作用的短插入 |
| 同场延长与补镜 | 已通过的原片、剪切点或保存帧，以及要继续的一个动作 | 先核实入口支持的续写。延长后核对动作轨迹、服装、对白与环境声。失败时重做具体一镜 |
| 局部修正 | 合格原片、时间码、问题和应保留的元素 | 如 6–8 秒杯子变形，只尝试修杯子与握持手，保留原对白节奏、机位和其它表演。未验证定点编辑时，重新生成该镜并剪接比较 |

## 转译到现有入口

- **Flow 主线。**优先用 Ingredients 分别指定角色、妆造与场景；或同机位关键帧约束构图。现有账户已做出单机位中文双人声画和海边多镜，跨镜复用音色、白模视频的控制力仍待验证。功能以所选模型、地区及账户界面为准。[Flow 模型和功能](https://support.google.com/flow/answer/16352836)
- **Grok 对照。**复用相同动作、角度及对白要求。网页实测有原声双人短句和剧情动作；当入口只有文字或有限图像引用，先将主体、场景与机位组合为一张参考关键帧，再明确只沿用画面设定，后续发生什么写入导演提示。当前多主体和音色独立锁定未验证。
- **声音与后期。**MiniMax 用于试音和可控对白的备选源。两人分开保存，不使用长段旁白填戏。FFmpeg／Remotion 保留原声，分轨处理和导出。若改音色、走后配或口型迁移，逐镜复审说话、听话与音画时机。
- 编剧与导演继续用统一的镜头字段。适配时把资产编号翻译为平台可用的上传、选择、首帧或文字引用。Seedance 的标签语法及接口上限仅作为其平台文档记录。

## 项目镜头卡范例

S15：次日咖啡角，约 8 秒。外貌 A 林夏、B 周远；B 深蓝针织，A 米色外套；同一版无人咖啡馆，窗左门右；两杯茶和两张票。机位 A 双人中景，B 左 A 右。入点 B 已就座，A 刚停在空椅旁。0–3 秒他把茶和车票推到桌中央；3–6 秒他说「昨天让你白等了。」A 闭口看他；6–8 秒他松开杯柄，A 先看茶再抬眼。出口两张票留在桌中央，供下一镜延续。室内底声和杯底轻响；保留原声。若后续补反打，另外记录每镜的视线、杯位、持杯手及男方声线。

执行记录最少保存：参考文件版本、模型与入口、实际可用输入、秒数和点数、原片与原声、缺陷时间码、获选或补拍理由。验收顺序为角色身份与空间 → 动作连续 → 双人台词与听感 → 接剪。下一轮先做同一咖啡馆三个机位的视听对照。本轮只完成指南梳理与制作规范更新。
