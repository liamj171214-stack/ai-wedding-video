# 人物与场景资产制作

**先建立两位角色的多视角参考和一个可拍正反打的咖啡馆。**逐场复用角色、妆造、场景和道具版本。简单三维用于锁空间、机位和走位；需要精确复现复杂表演或多集反复出镜时，再评估带骨骼、表情和口型的精细三维角色。

## 人物怎么做

1. 虚构样片从角色设计页定两张独立主图。真实新人用经授权的本人素材并核验所选入口支持的真人参考方式。
2. 每人先定一张光线中性的正脸作基准。逐张补 45 度、侧脸和全身，确认眉眼、鼻、脸轮廓及发际线。每个角度独立输出，便于按镜头选择。
3. 咖啡馆服装用男方深蓝针织、女方米色风衣，分别做全身和面料参考。另建婚礼与唐装造型，保持角色 ID 一致。年龄版本单列，跨年龄识别通过剧情道具帮助建立。
4. 两个人各保存一段中性试音和一段情绪试音。对白场次标出谁开口、谁闭口、谁先反应。率先做同一人正脸与侧脸两镜的音色对照，再做双人轮流对白。

## 场景怎么做

1. 主美术图先定咖啡馆风格和尺度。以后景书架、左窗、右门、中央木桌建立稳定空间。采集公开参考只作美术输入，也可生成无人背景。最终场景主参考独立保存。
2. 画一张俯视图，标窗、门、桌椅、两人视线轴、杯子位置。机位 A 正面双人中景，B 从女方肩侧看男方，C 从男方肩侧看女方。三台都在同一侧。昼夜变化只替换灯光和窗外条件。
3. 从同一空间出四张图：无人广角、双人机位的无人背景、两个过肩机位的无人背景。三次生成之间维持桌位、门窗、书架和主光方向。
4. 遇到转头、走入、从另一机位看或背景漂移，用 Blender 白模固定房间体块、桌椅与人物占位。输出俯视图、三个机位的静帧和约 5 秒走位或运镜参考。用生成影像负责最终质感。Seedance 2.5 官方指南有多视图与粗粒度白模、主体、场景组合参考，实际入口需验证。[参考方式](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)
5. 道具另建状态。咖啡馆保存杯子两个、车票两张、信封一个。镜头表记录入镜时在哪、由谁拿、离镜时放哪。海边另存信封完好及沾沙版本。

## 首轮资产清单与验收

| 资产 | 首批交付 | 镜头怎么引用 |
|---|---|---|
| A 林夏、B 周远 | 每人正脸、45 度、侧脸、全身、咖啡馆妆造和试听音频 | 同框引用两人，正反打只添当前角度必要参考 |
| C01 咖啡馆 | 无人主图、俯视图、同框与两张反打背景、早晨光版本 | 先同一套条件试拍，灯光变化留给跨日测试 |
| P01 杯子、P02 车票 | 独立参考图与桌面定位 | 推茶前后检查杯子数量、握持手和落点 |
| S15–17 咖啡馆和好 | 双人中景、男方说话、女方回应、动作衔接 | 检查两张脸、同一组音色、眼神、左右方向，以及碰杯位置和声音 |

目录建议按 characters、wardrobe、voices、locations、props、shots 分开。示例镜头引用 A 正面 v1、B 45 度 v1、C01 机位 B v1、P01 杯位 v1。候选记录同时保存模型、参数、原音、选择原因和被淘汰的时间点。先用第 15–17 镜验证三个机位，再把通过的资产规格扩展到站台、海滩和礼堂。
